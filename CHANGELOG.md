# Changelog

## Unreleased

### Added
- Added a friend list with friend requests and online status, signed in with the Minecraft account
- Added a friends button to the title screen and the pause menu, and the `O` key to open the friend list
- Added notifications for friend requests, accepted requests and friends coming online
- Added end-to-end encrypted chat with friends, including messages to offline friends and chat history
- Added unread message counts to the friend list and the friends button
- Added group chats of up to 10 members with a group owner who manages members and the name
- Added blocking players and deleting a chat for yourself
- Added a dropdown with actions for friends and groups, also opened by right-clicking them
- Added hosting your singleplayer world for friends from the pause menu, inviting friends or whole groups and joining
  worlds you were invited to (Fabric only for now)
- Added invite cards in the chat with a join button, and a key (`J`) to join the world from an invite notification
- Added rejoining a friend's world you were invited to before whenever they host it again
- Added a Friends' worlds section to the multiplayer server list

- Added announcements from the server, shown as a pinned chat and as notifications
- Added search and when friends were last online

### Changed
- Changed the friends screen to a social screen with a chat tab, listing every chat with a preview next to the open
  one, and a friends tab with friends, requests and blocked players side by side
